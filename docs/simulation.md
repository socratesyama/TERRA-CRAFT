# シミュレーションのモデル

定数は `src/simulation/constants.ts`。最大標高 2400 m、1 セル 1.2 km、海面 0.1。

- **水**: 窪地を Priority-Flood で埋めた面で最急降下の流向を決め、降水量を流域に集積する。窪地ごとに流入量を見て湖にする。ダムは高さの加算として扱う。
- **気候**: 気温は海面 + 緯度成分 − 6.5 K/km。偏西風で運ばれる水蒸気を、風上の斜面での上昇で降らせ、風下では断熱昇温で乾かす（雨陰）。
- **蒸発散と流出**: PET と降水から Budyko/Zhang 式で流出を出す。植生が多いほど蒸発散が増える。
- **侵食**: √流量 × 勾配 × (1 − 0.7 × 植生)。運べる量を超えた土砂は堆積する。地図の端以外では質量が保存される。
- **植生**: 気温と降水の制限の小さい方を純一次生産とし（Miami モデル）、容量に向けてロジスティックに成長する。川沿いは地下水の補給で上がる。
- **動物**: 草食は植生に応じて増え、捕食者は草食の 10% を生産に変える。移動は、資源の多い方へ向かう拡散（質量保存）。農地や道路、集落は生息地を減らす。
- **人**: 収容力（農業・漁業・交易）に向けてロジスティックに増える。圧力のかかった集落から分村し、余裕のある集落へ重力モデルで移住する。
- **経済**: 市場アクセス `M_i = Σ GDP_j / (1 + 輸送費_ij/10)²`、生産性 `1 + 0.8M/(M+400)`、`GDP = 人口 × 生産性`。港どうしは海路の費用が陸路の約 3 分の 1。
- **因果の連鎖**: 干渉の 6 tick 後に、前後の統計を比べて「山を削った → 勾配が変わった → … → 川の延長 +…km」の形でログに残す。

これらは、直感的に確かめられる規模に簡略化した教育用のモデルであり、予測のための数値モデルではない。
