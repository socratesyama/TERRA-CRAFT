# TERRA CRAFT

等高線を描くと地形が生まれ、雨が降り、川が流れ、森が育ち、人が集まる。ブラウザだけで動く、創造的な地理シミュレーション。

地形が違うだけで、水・気候・生態系・人の暮らしがどう変わるかを、手軽な操作で確かめられる。

## 動かす

```bash
npm install
npm run dev      # 開発サーバー
npm test         # シミュレーションのテスト
npm run build    # 本番ビルド（dist/）。型検査は npm run typecheck
```

`main` への push で GitHub Pages に公開される（リポジトリの Settings → Pages で Source を GitHub Actions にする）。

## 使い方

1. 世界をなぞって等高線を描く（高さは左のスライダー）。または「地形の例」から選ぶ。
2. 「雨を降らせる」を押し、「時間を進める」で世界を動かす。
3. 山削り・盛り土・伐採・植林・ダム・埋め立てで干渉する。何が起きたかは右の記録に因果の連鎖で残る。
4. 降水量と気温を変えて、気候の違いを見る。
5. 「共有」で、世界を再現する URL を作る。サーバーは使わない。

## 取り入れた科学モデル

| 領域 | モデル |
|---|---|
| 水 | Priority-Flood による窪地の処理、最急降下の流向、流量集積、湖の貯水と蒸発損失 |
| 気候 | 気温減率 6.5 K/km、Magnus 式の飽和水蒸気圧、偏西風下の地形性降雨と雨陰 |
| 水収支 | Budyko/Zhang 式の流出、可能蒸発散量、乾燥度指数 |
| 侵食 | ストリームパワー型の侵食、土砂の輸送能力と堆積（湖・三角州）、植生による被覆効果 |
| 植生 | Miami モデルの純一次生産（気温と降水の制限の小さい方）、河畔の地下水補給、ロジスティック成長 |
| 動物 | 草食動物のロジスティック成長、Lotka-Volterra の捕食者（栄養段階効率 10%）、理想自由分布による分散、生息地の分断 |
| 人 | 食料の収容力によるマルサス型の成長、重力モデルの移住、低コスト経路の道路、洪水リスク |
| 経済 | 新経済地理学の市場アクセス、市場規模に応じた生産性、重力モデルの交易、水運の費用優位（港） |

シミュレーションは決定的（乱数は座標とシードのハッシュ）。描いた線と干渉の記録を再生すれば、同じ世界に戻る。

## 構成

- `src/simulation/` エンジン（描画から独立。Web Worker で動く）
- `src/terrain/` 等高線 → 高さ場、メッシュ、色、地形の例
- `src/render/` Three.js のシーン
- `src/state/` Zustand のストア
- `src/ui/` 画面
- `tests/` Vitest

詳細は [docs/](docs/) を参照。

## 検証状況

- シミュレーションの科学的な性質（質量保存、雨陰、侵食の向きなど）と URL 共有は、単体テスト 67 件で確認した。
- 画面（React / Three.js 部分）は、依存パッケージを入れた環境での実行、型検査、ブラウザでの目視確認を**まだ行っていない**。最初の `npm run build` で型エラーが出る可能性がある。
- 192×192 での 1 ステップは、テスト環境で 150 ms 未満。目標の 50 ms は未確認。

## Cloudflare で公開する

Workers（静的アセット）の場合は、リポジトリの `wrangler.jsonc` が `dist` を配信する。

- Build command: `npm install && npm run build`
- Deploy command: `npx wrangler deploy`

Pages の場合は、Build output directory を `dist` にする。
